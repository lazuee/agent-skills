## Write the Tagline as One Plain Sentence

Put one blockquote directly under the title. Start with the package name in backticks. Say what it does, then what changes for the user. No adjectives that cannot be measured.

**Why:** adjectives like "powerful" or "seamless" tell the reader nothing and make them distrust the rest. The effect on the user (shorter output, fewer steps, smaller bundle) is the useful part.

**Incorrect:**

````markdown
> A powerful, seamless toolkit that supercharges your workflow with blazing-fast config syncing.
````

**Correct:**

````markdown
> `dotsync` copies your dotfiles from a git repo to your home directory. It only touches files that changed, so a sync takes seconds.
````

Two short sentences are fine when the second states the effect. Three is too many.
