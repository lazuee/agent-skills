## lazuee/agent-skills

> `lazuee/agent-skills` is a collection of agent skills for the tools and workflows I use. It gives reusable guidance for documentation, schema conventions, routing patterns, and other repo-specific practices.

### Installation

Install the skill package with the `skills` CLI:

```bash
bunx skills add lazuee/agent-skills
```

### Usage

This repository is organized as a set of skill folders under `skills/`. Each folder contains a `SKILL.md` file and related rules for a specific workflow or convention.

Compatible tools that support the `skills` CLI can load these skills after installation.
